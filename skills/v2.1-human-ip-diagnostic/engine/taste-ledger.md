# Taste Ledger Engine

## Purpose
Capture cultural/aesthetic evidence without turning preference into pseudo-psychology.

## Record
- id
- object
- category
- attraction
- user_meaning
- source_ids
- proposed_motif
- recurrence
- counter_evidence_ids
- confidence
- confirmation
- visibility

## Categories
FILM | ANIMATION | BOOK | MUSIC | GAME | PERSON | CHARACTER | ART | BRAND | PLACE | ARCHITECTURE | OBJECT | FOOD | OTHER

## Rule
`Object → Attraction → User Meaning → Repeated Motif → Possible Signal → Human Confirmation`

The object title alone is weak evidence.
