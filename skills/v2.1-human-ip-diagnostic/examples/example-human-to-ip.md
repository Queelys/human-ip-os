# Example — Human DNA to IP DNA

## Human understanding
Evidence suggests a person repeatedly:
- builds systems from ambiguous material,
- is asked by others to explain complexity,
- is culturally attracted to work combining old and new,
- wants to create public tools but has limited proof of teaching at scale.

## What not to do
Do not immediately declare:
“Future-of-humanity thought leader.”

That converts aspiration and taste into unsupported authority.

## Positioning Lab
Path A: systems builder for a specific professional audience
Path B: public learner documenting experiments
Path C: curator/translator connecting historical ideas with emerging technology

Each path shows source evidence, proof gaps and exclusions.

## Human decision
User edits and selects Path B+C hybrid.

## Public Self
Only PUBLIC_CONFIRMED evidence enters IP DNA.

## Proof Mission
Run a bounded public research/teaching experiment, collect outcomes, then convert verified outcomes into PROOF.

The brand grows from action, not from louder claims.
