# Super Individual OS Canvas

## Human Core
Only the human should own:
- values
- judgment
- taste
- relationships
- accountability
- sensitive decisions

## Knowledge OS
- capture
- questions
- sources
- concepts
- synthesis
- evergreen ideas

## Project OS
- ideas
- priorities
- projects
- content/works
- calendar
- review

## AI Collaborators
For every role define:
| Role | Input | Output | Human Reviewer | Failure Boundary |
|---|---|---|---|---|

## Production Loop
Input → Think → Decide → Create → Publish/Act → Measure → Reflect → Knowledge

## Tool Truth Map
For each system define one source of truth.
Never create uncontrolled bidirectional sync.

## Weekly Review
- What did I notice?
- What did I learn?
- What did I create?
- Who did I help?
- What became a durable asset?
- What should stop?
