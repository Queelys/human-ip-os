# HUMAN → IP → OS V1.1
## Human Discovery Method

**Know yourself before you brand yourself.**

V1.1 is the complete upgrade of the original V1.0 methodology. It preserves the original 9-stage HUMAN → IP → OS system and adds a deeper human-understanding layer before personal-brand design.

### Core question
> If we temporarily ignore personal branding, who is this person really?

### Human DNA
- EXPERIENCE｜经历
- CAPABILITY｜能力
- CURIOSITY｜好奇
- VALUE｜价值
- TASTE｜审美
- DESIRE｜渴望

### New in V1.1
- Human DNA ≠ IP DNA
- Taste & Cultural DNA
- progressive cultural prompts
- motif discovery with human confirmation
- public/private boundary architecture
- anti-pseudo-psychology rules
- stronger provenance and evidence discipline
- contradiction preservation
- Human DNA review gate before IP translation

### Taste inference rule
`Object → Attraction → User Meaning → Repeated Motif → Possible Signal → Human Confirmation`

The title of a film, book, brand or city is never enough to infer personality.

### Original V1 system preserved
1. Deep Discovery
2. IP DNA
3. Life Narrative
4. Brand Constitution
5. Content Universe
6. Signature Project / Action IP
7. Super Individual OS
8. Public Interface / Website
9. Vibe Coding Build Pack

### Best first prompt
> Use HUMAN → IP → OS V1.1. Start in Human Discovery mode. Interview me progressively across Experience, Capability, Curiosity, Value, Taste and Desire. Do not define my IP until the Human DNA gate is strong enough. Treat taste as meaning to explore, not personality evidence.

### Principle
A person is larger than their brand.

**Human DNA → Public Self → IP DNA → Brand System**
