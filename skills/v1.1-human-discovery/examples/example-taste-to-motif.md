# Example — Taste Object to Confirmed Motif

## Raw inputs
- Film A: user says they love the collision of ancient myth and future technology.
- City B: user says they love visible historical layers beside experimental architecture.
- Object C: user collects handmade objects that use modern fabrication.

## Wrong shortcut
“You are a futurist who loves tradition.”

## Correct process
1. Record each object separately.
2. Capture the user's own attraction and meaning.
3. Notice recurrence: `ancient ↔ future`.
4. Preserve counter-evidence.
5. Ask:
   “Across these three examples, I notice you may be repeatedly drawn to the tension between the ancient and the future. This is only a hypothesis. Does that feel true?”
6. Store response as CONFIRM / EDIT / REJECT / NOT SURE.
7. Only after confirmation may the motif influence public positioning or visual direction.
