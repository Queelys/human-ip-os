# C004 AUDIO QC — 声音系统与混音

所有数值都来自 2026-10-11 从零验收运行的真实日志（`evidence/c004/audio-report.json`、`qc-final.json`、`audio-determinism.json`）。

## 1. 声音身份映射（C004.1）

代码：`src/audio/identity.ts`。所有身份参数都从 C002 spec（`DEFAULT_MI_SPEC`，指纹 `cd2e236379d37be5`）**读取**，没有另建协议。脉冲包络直接调用 C002 的 `pulseIntensity`。

| 读取项 | 来源 | 值 |
|---|---|---|
| 三锚点 ID | `spec.anchors[].id` | A1 / A2 / A3 |
| 相位偏移 | `spec.pulse.phaseOffsets` | 0 / 1/3 / 2/3 |
| 身份脉冲频率 | 1 / `spec.pulse.periodSeconds` | 1/3 Hz（周期 3 s） |
| 脉冲宽度 | `spec.pulse.width` | 0.25 |
| 固定随机种子 | `spec.seed` | `0x4B4C4D49` |

由身份派生的表现选择（不属于身份协议本身）：

- **音高**：A1 : A2 : A3 = 1 : q/p : p = 1 : 3/2 : 2，对应 660 / 990 / 1320 Hz。
- **声像**：0.7·sin(2πs)，A1 居中，A2 偏右 0.61，A3 偏左 0.61。

单元测试用一份修改过的 spec（周期 4 s、偏移 0.1/0.5/0.8）调用映射，验证映射随 spec 变化，没有把协议写死。

## 2. 五个轨道（C004.2）

都是全局时间 t 的确定性离线生成，48 kHz，float64 计算。控制信号取自 C003 的 `envelopesAt`、`filmDeformationParams`、`arcRevealAt`，以 1 ms 控制率采样后线性插值，与画面共用同一时钟（帧号 = t × 30）。

| # | 轨道 | 构成 | 跟随画面的量 | 时间分布 |
|---|---|---|---|---|
| 1 | 本体低频 | 55 Hz，加 2、3 次谐波，左右轻微失谐 | 背景强度、Φ 缩放；Φ 扭转使音高弯曲 ±3 % | 0–30 s（2.5 s 渐入，29–30 s 收尾） |
| 2 | 身份脉冲 | 每锚点一个正弦加 0.2 倍 3 次谐波（相位锁定） | C002 `pulseIntensity` × 锚点可见度 × 脉冲增益，与画面锚点辉光用同一组量 | 可听脉冲：A1 从 3.375 s，A2 从 7.375 s，A3 从 8.375 s |
| 3 | 神经颗粒 | 8–30 ms 汉宁窗正弦颗粒，1.8–5.2 kHz | 种子泊松过程，按「信号包络 × 网络亮度」保留 | ACT III–IV（约 11–25 s） |
| 4 | 拓扑共振 | 110 Hz × {1, q/p, p, q} | 主结揭示比例与核心辉光；Φ 扭转带来闪烁调制 | ACT II 起，随揭示增长 |
| 5 | 终章和声 | 220 Hz × {1, 4/3, 3/2, 2, 9/4}，只含质因数 2 和 3 | ACT V 共享共振包络，以及与锚点同步辉光相同的 0.75 + 0.25·cos(2πt/3) 呼吸 | 约 26.7–30 s |

声音时间轴（C004.3）：0–5 s 未分、5–11 s 破缺、11–18 s 织生、18–25 s 易形、25–30 s 自见。这是 C003 帧区间 0–149 / 150–329 / 330–539 / 540–749 / 750–899 换算成的时间，所有事件都按全局时间计算。

频率分离：任何持续声部与三个脉冲音高及其 3 次谐波至少相隔 25 Hz，由单元测试保证。首轮 QC 发现终章 220 × 3 = 660 Hz 与 A1 撞频，已移除该声部（D-020）。

素材：没有任何外部音乐或音效样本，全部为程序化合成。

## 5. 身份脉冲一致性（解码后的最终成片）

- **峰值时刻**：25 个可听脉冲的实测峰值（整周期 Goertzel 能量质心）与 C002 理论时刻最大偏差 14.5 ms（小于 1 帧）。
- **周期**：在平稳区 9–26.5 s 内实测 15 个间隔，为 2.9999–3.0001 s，spec 为 3 s。平稳区指所有可见度和增益渐变结束后、ACT V 共振开始前。
- **相位差**：实测 A2−A1 = 0.3333、A3−A1 = 0.6667，与 spec 一致。
- **映射**：音频身份映射（ID、偏移、周期、种子）与 C002 spec 完全相等。
