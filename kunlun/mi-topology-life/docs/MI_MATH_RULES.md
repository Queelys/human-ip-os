# MI Math Rules

本文件区分两类保证：

- **数学保证**：在实数算术下成立的定理或证明梗概。
- **数值检查**：浮点实现的测试。用来发现实现错误，**不是严格拓扑证明**。

## 1. K 是嵌入的正则闭曲线（数学保证）

记 t = 2πs，K(t) = ((R + a cos qt) cos pt, (R + a cos qt) sin pt, a sin qt)，p = 2，q = 3，0 < a < R。

**闭合与光滑**：各分量都是 t 的 2π 周期三角多项式，所以 K 是 C^∞ 闭曲线，切向量 K′ 与所有高阶导数在 s = 0 和 s = 1 处取值相同。

**正则**：

```
|dK/dt|² = a²q² + p²(R + a cos qt)²  ≥  a²q² + p²(R − a)²  > 0
```

所以 K 处处正则。下界 2π·√(a²q² + p²(R − a)²) 由 `knotMinSpeedBound` 给出。

**嵌入（无自交）**：K 位于环面 T = {((R + a cos φ) cos θ, (R + a cos φ) sin θ, a sin φ)} 上。当 R > a > 0 时，(θ, φ) ↦ T 是 (ℝ/2πℤ)² 到 ℝ³ 的单射。若 K(t₁) = K(t₂)，则 p(t₁ − t₂) ∈ 2πℤ 且 q(t₁ − t₂) ∈ 2πℤ。因为 gcd(p, q) = 1，存在整数 m、n 使 mp + nq = 1，所以 t₁ − t₂ ∈ 2πℤ。因此 K 在一个周期内是单射。

**纽结类型**：K 是环面结 T(2,3)。经典结论：当 |p|, |q| ≥ 2 且互素时 T(p,q) 非平凡，T(2,3) 即三叶结。三叶结是**手性**的（与其镜像不同痕），所以身份要求同时固定手性（见 §4）。

## 2. Φ 的原语都是保定向微分同胚（数学保证）

| 原语 | 映射 | 逆映射 | Jacobian 行列式 |
|---|---|---|---|
| 旋转 | x ↦ Rx，R ∈ SO(3)（单位四元数 q） | q̄（共轭） | +1 |
| 缩放 | x ↦ s·x，s > 0 | 1/s | s³ > 0 |
| z 扭转 | (x, y, z) ↦ (Rot_z(kz)(x, y), z) | k ↦ −k | +1 |

扭转的 Jacobian 为 [[c, −σ, ∗], [σ, c, ∗], [0, 0, 1]]，其中 c = cos kz，σ = sin kz，行列式 c² + σ² = 1。扭转保持 z 与到 z 轴的距离不变，所以逆映射是精确的。

复合 Φ = P_n ∘ … ∘ P_1 的逆为 P_1⁻¹ ∘ … ∘ P_n⁻¹（`invertDeformation`）。

## 3. Φ 是环境同痕，保持纽结类型（数学保证）

每个原语都在一条从恒等映射出发的连续微分同胚路径上：

- 旋转：R_τ = exp(τ·log R)，τ ∈ [0, 1]（SO(3) 道路连通）
- 缩放：s_τ = s^τ
- 扭转：k_τ = τk

把各路径拼接，就得到从 id 到 Φ 的环境同痕 H_τ。所以 Φ(K) 与 K **同痕**，纽结类型与手性都不变。参数 (yaw, pitch, roll, scale, twist) 连续变化时，Φ 也在这一族中连续变化。

## 4. 排除的形变（规则）

- **镜像 / 反射**（det = −1）：会把右手三叶结变成左手三叶结，改变身份。单位四元数只表示 SO(3)，缩放必须 > 0，所以在类型层面无法构造反射。
- **任意顶点扰动**：可能产生自交（穿越），破坏同痕类。形变引擎不提供这一原语；运行时遇到未知原语直接抛错（`Forbidden deformation primitive`）。
- **非正缩放**：s ≤ 0 会退化或反射；`uniformScale` 拒绝 s ≤ 0、NaN 和 ±∞。

外围网络（`neuralGraph.ts`）可以有任意的时间依赖变化，因为它不属于身份核心。

## 5. 锚点与核心图（数学保证）

- A_i(t) = Φ_t(K(s_i))。Φ_t 是双射，s_i 互不相同，所以三个锚点在任何时刻都互不重合。
- Φ_t 对 t 连续，所以锚点轨迹连续。
- 参数 s_i 不随 Φ 变化，所以沿 Φ_t ∘ K 的循环顺序 A1 → A2 → A3 保持不变。
- G 是 spec 中的组合数据。Φ 只作用于点；核心边只在锚点像之间绘制，不改变关系。

## 6. 脉冲协议（数学保证）

φ_i(t) = frac(t/T − o_i)，I_i(t) = w(φ_i(t))，其中 w(φ) = ½(1 − cos(2πφ/W))（φ < W 时），否则为 0。

- φ_1(t) − φ_i(t) ≡ o_i − o_1 (mod 1)，对所有 t 成立（相位差固定）。
- I_i(t) = I_1(t − o_i·T)（平移等变）。
- I_i 是 t 的闭式函数，不依赖上一帧状态。
- 默认配置 W = 0.25 ≤ 最小相位间隔 1/3，所以任何时刻最多一个锚点在脉冲中。

## 7. 时间驱动

`motionParamsAt(spec, t)` 是 t 的闭式函数：yaw = 2πt/12，pitch = 0.25 sin(2πt/10)，scale = 1 + 0.08 sin(2πt/6)，twist = 0.6·k_max·sin(2πt/10)。因为 0.08 < 1，所以对一切 t 都有 scale ∈ [0.92, 1.08] ⊂ [0.25, 3]，且 scale > 0。

## 9. 不在 V1.0 保证范围内

- **渲染管道的几何厚度**：K 是零厚度曲线。管道半径 r 在 2r 接近链间距时会在视觉上自相交，但身份曲线本身并不相交。实测链间距：未形变 0.869；最大扭转时 0.676；缩放 0.25 加最大扭转时 0.169。表现层的管道半径必须随 Φ 的缩放调整（见 C002_ACCEPTANCE 已知风险）。
- **跨平台逐位一致**：不同 JS 引擎的 `Math.sin`/`cos` 可能差 1 ulp。实测浏览器与 Node 之间的差 ≤ 4.4e-16，所以容差设为 1e-9。
