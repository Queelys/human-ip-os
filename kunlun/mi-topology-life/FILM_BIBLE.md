## 2. 弥是什么

弥**不是人形角色**。弥是一个数字生命体，由三层结构共同构成：

1. **拓扑结构（骨）**：一个闭合、可定向的曲面，作为身份的不变核心。
2. **神经网络（脉）**：沿拓扑骨架分布的节点与连接，表现"思考"与信息流动。【C002+ 设计】
3. **星系式粒子（息）**：环绕核心的粒子场，表现弥与外部世界的边界和呼吸。

## 3. 身份内核（Identity Kernel）

代码唯一来源（自 C002 起）：`src/identity/miKernel.ts` 中的 `DEFAULT_MI_SPEC`，即 **MI = (G, K, A, P, Φ, σ)**，完整定义见 [docs/MI_IDENTITY_SPEC.md](docs/MI_IDENTITY_SPEC.md)，数学规则见 [docs/MI_MATH_RULES.md](docs/MI_MATH_RULES.md)。C001 使用的 `src/core/identity.ts`（`MI_IDENTITY`）是从它派生的视图。下表为 C001 时定义的拓扑摘要：

| 字段 | 当前值 | 含义 |
|---|---|---|
| `seed` | `0x4B4C4D49`（"KLMI"） | 全片根种子；所有随机由此派生 |
| `genus` | 1 | 核心曲面亏格 |
| `eulerCharacteristic` | 0 | χ = 2 − 2g |
| `orientable` | true | 可定向 |
| `knot (p, q)` | (2, 3) | 核心链为三叶结（trefoil），gcd(p, q) = 1 |

> ✅ 已确认（2026-10-10 人工验收）：(2, 3) 三叶结为弥的正式核心身份参数，象征"最简单的非平凡纽结"——最小的自我缠绕。修改须走第 4 节的变更流程。

## 4. 拓扑不变量（不得为视觉效果悄悄破坏）

以下性质在**每一个镜头、每一帧**都必须成立：

- **INV-1 亏格守恒**：弥的核心曲面始终 genus = 1，χ = 0。镜头可以变形、缩放、着色、溶解表皮，但不能撕裂或粘合核心曲面。
- **INV-2 纽结类型守恒**：核心链的纽结类型保持 (p, q) 不变。允许光滑同痕变形，不允许"穿过自身"。
- **INV-3 种子守恒**：同一子系统在任何镜头中使用同一派生种子；粒子"同一颗"在不同镜头中身份一致。
- **INV-4 内核只读**：镜头层不能修改 `MI_IDENTITY`；需要变化时只能在表现层叠加。

确需改变不变量时（例如剧情需要"拓扑相变"），必须：在本文件登记 → 修改内核版本号 → 更新测试 → 人工批准。不得在镜头代码中绕过。

自动化保护：`tests/identity.test.ts` 对核心网格计算欧拉示性数并与内核比较。

## 5. 架构分层

```
身份内核层  src/core       纯数据/纯函数；不知道镜头和时间轴
    ↓ 只读
表现层      src/scenes     由 (kernel, frame, seed) 决定的画面元素
    ↓ 组合
镜头层      src/compositions  摄像机、光、时长、剪辑
```

## 7. 确定性规范

- 帧号是唯一时钟；运动 = f(frame)。
- 禁止：`Math.random`、`Date.now`、`performance.now`、`new Date`、`THREE.Clock`、R3F `useFrame`（ESLint 强制）。
- 任何帧可单独、乱序、并发渲染，结果逐像素一致（`npm run verify:determinism`）。
